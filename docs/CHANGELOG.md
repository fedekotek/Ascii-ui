# Changelog

Oldest first. Versions as published, now at https://ascii.fedekotek.design (Vercel deploys `main` on every push). Single files for the published versions from v2 to v9.3 are in `archive/`. From v10 the history is in git.

- **v1** Hybrid prototype: semantic HTML on a character grid, CSS lines through cell centers, ASCII state glyphs. Button, input, checkbox, radio, switch, slider, tabs, card, dialog, progress, toast. Light and dark.
- **v2** Brutalist rewrite: ramp as hierarchy, frames as strings, bitmap titles, posterized hero, halftone bars, paper and ink palette.
- **v3** "Más rosca": spinning torus hero, theme curtain, developing titles, rim march/burst, input ripple, ramp checkbox marks, diagonal bar edges.
- **v4** Glitch: signal palette, canvas hero with streaks/blocks/RGB split/tearing, shard sparks, jolt, glitchy dialog, color-bar curtain, glitch slider and switch, scanlines.
- **v5** (unpublished, no approval) Site: views, Blocks, Charts, boot, destructible UI, command palette, photo hero, scroll-as-signal, VHS HUD, signature + poster, tilt, invaders.
- **v6** Same as v5 plus fixes; published later as part of v8.
- **v7** shadcn structure: index chips, Preview/Code tabs, Installation; 18 new components; 12 new blocks (personal content); sectorized LCD pictures; QA passes at 390/820/1440.
- **v8** Themes (6 presets, pickers, ramp editor, tokens), Play (hero knobs, words, snapshot), Code tab with CSS+JS, install steps. First publish that went through.
- **v9** Humanized sound with fatigue, mobile menu sheet, more air between sections, Apps view (Chirp, Tape, Static support), mobile tap-target and text-size audits.
- **v9.1** Boot screen gets the poster treatment (split bitmap title, color bars, halftone progress, streaks).
- **v9.2** Sliders no longer open the Android keyboard (`inputmode="none"`, blur after touch).
- **v9.3** Titles fit: drop bars, then halve scale, based on measured columns; handles accessibility font scaling.
- **v9.4** Shatter uses the component's own characters, frames, glyphs and LCD pixels, with their colors.
- **v10** This repo: split into `index.html` + `css/` + `js/`, `build.py`, docs, QA scripts, archive.
- **v10.1** One clock: the 33 `setInterval`s become tasks on a single `requestAnimationFrame` loop (`A.every`, `A.times`), with gates, self-stopping handles, a global pause and `qa/clock.py` to keep it that way. No visible change, same cadences.
- **v10.2** The page uses the screen. `--maxcols` caps the width in characters and steps up at 1024, 1280 and 1600px (80, 100, 124, 165 characters). Components and Blocks become galleries of one, two or three columns, packed against the 24px rows so short sections do not leave holes. Sections with a table, a chart, a picture or a timeline stay full width, and Charts stays one column because charts draw to the page width. `qa/breakpoints.py` checks the column counts, the character snap, overflow and overlap at eight widths.
- **v10.3** The width pass, reviewed. Cards keep alphabetical order in rows instead of packing masonry-style, so the index and the page agree and the rules line up. Less air above each card. Installation opens the view at full width instead of competing with the first component. Heatmap and Donut sit in columns, only the charts that draw to the page width take the row, and the footer game is centered. A Code tab takes the whole row while it is open. An open menu covers its neighbor instead of blending into it.
- **v10.4** Navigation. The top bar gets the name of the kit, and from 1280px a sticky sidebar lists the sections of the view you are in and marks the one you are reading. The hero stops cutting its scene at the edges, six characters of fade on the sides and two rows top and bottom.
- **v10.5** The bar becomes a real top bar: outside `main`, the width of the window, stuck from the first pixel, views collapsing into the sheet under 768px. The sidebar arrives at 1024px instead of 1280px. The hero's glow moves from the content column to the window, so it stops ending in a hard vertical line on a wide screen. Page transitions are twice as fast (curtain, datamosh and the entrance stagger). Poster titles are a size smaller and their cap is now the `--ptitle` token.
- **v10.6** Review fixes. The closed menu sheet no longer shows at the foot of every page. The views stay in the `[=]` sheet until 1024px, since between 768 and 1023px One pager sat under sound and theme. The hero gives its rows back when the window grows again, and never takes more than 45% of the window. The sidebar lists what the chip index lists (30), with Installation and Rules as loose entries where the page has them, marks the section a jump lands on (the line is read from the scroll margin, not hard-coded) and nothing while you are above the first section, shows a thin scrollbar when it is taller than the window and starts two rows under the hero. The bar keeps a word on every control (Sound, Theme, and `>_` for Commands, one name everywhere), each at least 5 characters wide, and the name steps aside under 450px to make room. The sheet puts its controls above the section list, names that list, hides the sections the Blocks filter hides (and the index count follows), and opens with focus on the current view. Selected tabs, days, toggles and menu entries lose their blue edge (blue is focus). On a phone the Play stage is drawn eight rows tall and actually stays pinned over the knobs (its section sticks, not the stage); a jump to Words or Knobs lands just under it. At 1024px the gallery is one column beside the sidebar. `qa/qa.py` fails if a closed dialog is visible and `qa/breakpoints.py` checks the bar for overlap, that the views are always reachable, and runs at 800 and 900px too.
- **v10.7** The rest of the review. The Filters sheet gets its Reset and Apply back (a menu rule hid them), plus an `[x]` and tap-outside to close. Both sheets close on click, so a tap above them no longer lands on the page underneath. The sheet carries Show grid, which was out of reach under 1024px. Tapping a dropdown's frame opens it. The camera message prints under its buttons. A landscape phone drops the hero, its photo buttons and its glow. Switching views lands one row under the bar, Play included. Two quick theme taps cancel out.
- **v10.8** Eight critics, five builders. Scanlines cover everything, dialogs and the loader included. The loader is the first paint, under 1.5s, skippable. Navigation: every view and section has an address (`#components/button`), Back works, the phone bar reads `[=] ascii/ui / View >_`, tablets get the tabs, the menu is a full-screen index, one transition per action and one lock. The hero is curated: one line, a short lede, See components and Open in Play; the photo, camera and poster toys live in Play with names. Components opens on Button, Get the kit closes it. Toasts clear the control you tapped, tooltips close on touch, the calendar and charts work by keyboard, entrances play once, reduced motion silences everything. Copy follows one glossary, cyan means focus only, light theme severity reads right.
- **v10.9** The redesign. Type goes to 14px and a row to 21px; the scripts read the row as `A.ROW`. Five views: Home, Components, Blocks, Charts, Themes. Play, Apps and One pager go (js/50 and `qa/apps-menu.py` with them), old `#play`, `#apps` and `#onepager` links land on Home, and the One pager toys move to Themes as Labs. Home gets the hero: the ring spelling COPY IT / OWN IT, a lede, See components and Get the kit, one line of numbers and Feed the ring a photo, then Where to start (four tiles) and Questions. A Try it strip of four live parts sat between them at first; it went in d363d02. The invaders stay on Home; the footer line shows on every view. Docs views open with one bitmap title and one lede, section posters give way to bold uppercase headings, Components come in five groups (Form, Overlay, Display, Feedback, Navigation) on the page and in the sidebar, Get the kit and Rules close the page but open the sidebar as Getting started, and Blocks are one per row. The bar: the name on the left is Home (its tab exists for the router, not drawn), the views, then Search as a field (`[ Search... Ctrl K ]`, `[/]` below 1024px) and three glyphs, Glitch `/\/`, Sound `<)))` and Theme `-O-` or `(C`, with their words from 1280px. Below 1024px the `[=]` menu holds the views, Show grid and Glitch. The crumb goes. Search replaces the command prompt (js/80, css/18): a list of Views, On this page, Settings and Tricks that never starts blank, every section of every view searchable, and a Run row for typed commands. 18 stylesheets, 7 scripts.
- **v10.10** After the redesign. Home drops Try it and goes from the hero to Where to start. The two headline lines sit together on a screen; on a phone the ring shrinks into the gap between them, and it shades through violet and magenta (no blue, blue is focus). Opening Code keeps a component in its column and the code wraps. A jump lands on a section's title. Body type is Geist Mono 300, gray text, the bar and the sidebar 400. Blocks group by their filter categories on the page and in the sidebar, the chips follow that order, and group labels hide when a filter empties them. Themes sections sit one row apart and the sidebar drops its count. The leftovers of the removed views go and css/11 and css/15 are renamed.
- **v11.0** A real kit. `kit/ascii-ui.css` and `kit/ascii-ui.js` are files you link from your own page, and `kit/starter.html` is a page that already links them; the Code tab gives you the HTML to paste. The deploy serves the single file and `kit/` only, from `site/` (built by `build.py`, see `vercel.json`), with link previews. MIT license. Accessibility: frame characters are silent for screen readers and every control has a visible focus state. Mobile fixes. Charts fit their column. Components use the names people type (Breadcrumb, Pagination, Separator, Toggle group, Input OTP, Card and dialog), Search knows the other names too (accordion, drawer, modal, btn, install and more), forgives one typo, offers five common components when empty and reads its result count to screen readers. Home says who it is for, and Feed the ring a photo moves under the tiles. The version is in the footer.
- **v11.1** A kit that holds up in a real app. Kit 1.1.0: radios keep their names across forms, components tear down and re-arm when they are removed and put back (`ASCIIUI.destroy`, `ASCIIUI.validate`), a real reset, toasts over dialogs, OTP and calendar values reach their forms, link pagination, a Table block, pinned `/kit/1.1.0/` files and a kit changelog. Kit 1.1.1 fixes pagination that lost the page it was asked for, events that fired on load, calendar values outside their range, slow radio naming and spinners kept in memory under reduced motion. The Code tab is built from a clean copy of each demo, never mid-glitch or mid-use, and names the classes a block uses that only the site has. Foundations, first in Components: the 14 color tokens with their dark and light values, the grid, the nine-step ramp (space to @), the eight tones and the states of every form component, readable on a phone without scrolling sideways. Code boxes say "more below" while there is more below. Deep links hold at every width. Glitch reads on focus, and Hot dog, Game Boy and Amber pass contrast. Counts are honest: 30 components on the page, 28 in the kit, Command and Picture marked site only in the sidebar. For agents: `llms.txt` and a generated components reference. One release command, `qa/release.sh`.
- **v11.2** Kit 1.2.0 and a page that rests. Four overlay components: Popover, Combobox, Alert dialog and Context menu, so 34 components with 32 in the kit. A Usage tab on every component (when to use it, anatomy in characters, states, keys, accessibility, do and don't), `js/90-usage.js` and `qa/usage.py`. Print, Windows High Contrast and more contrast (`css/29-print.css`). No external requests: Geist Mono is self-hosted and inlined, the build minifies, hashes every inline script into a CSP and fetches the Code tab's kit text on first use. Scanlines off unless `crt`, slabs lose their colored edges, sparks, tears, the tracking band and the boot glow are characters, and decoration no longer borrows cyan, lime or yellow. The clock sleeps when nothing is due, and `qa/budget.py --idle` joins the release bar (17 steps). Touch: taps act on release, a long press breaks only titles, after 900ms. Home gets How it was made, the reel (loaded on tap), credits, and NO SIGNAL for an unknown address. `docs/ACCESSIBILITY.md`.
