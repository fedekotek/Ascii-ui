ascii/ui

Thirty shadcn-style components in an ASCII skin. Frames, fills and shadows are strings of characters. Plain HTML underneath, bad signal on top.

For designers and developers who copy a component and own the code.

0 dependencies. 30 components, 28 in the kit. 2 kit files.

Questions

Is this accessible?

The characters are paint. Underneath are native controls with labels, focus states and keyboard support, and decorative glyphs are hidden from assistive tech. Reduced motion switches the glitch off.

Does it need a framework?

No. The kit is two files, ascii-ui.css and ascii-ui.js. The components are classes and custom properties, so they drop into anything.

Why monospace only?

The grid is the design. Every width is a number of characters and every height a number of rows, which is what lets strings work as borders.

Can I turn the glitch off?

Yes. The Glitch switch kills it, the slider scales it, and the page respects reduced motion.

30 components, grouped by what they do. 28 are in the kit, Command and Picture are site only. Open Code on any of them and take the HTML, the CSS and the JS. New here? Get the kit, then read the rules.

  

    
Rules

    

    
@@ %% ## ** ++ == :: ..

    
    
      
  • Weight is character density. @ is the loudest thing on the page and . is the quietest.
    • 
      
  • Frames, rules, fills and shadows are strings of characters. Hierarchy comes from which character.
    • 
      
  • Big type is a bitmap: every pixel of a headline is a block of characters.
    • 
      
  • Color is signal: magenta acts and marks the worst state, cyan focuses, lime confirms, yellow warns.
    • 
      
  • Glitch is feedback. It fires when you touch something or when a state changes, and the slider turns it down to zero.
    • 
      
  • Everything arrives broken and fixes itself: elements glitch in as they enter the screen, text decodes left to right.
    • 
      
  • Sound is feedback too. Square-wave blips and crushed noise, never music.
    • 
      
  • Nothing jumps. State changes travel through the ramp, one character at a time, at a low frame rate.
    • 
      
  • Underneath it is plain HTML: buttons, inputs, a dialog.
    •

Grid

      
One cell is 1ch wide and one row tall. Every width is a number of cells and every height a number of rows.

      

        
Cell
1ch by 21px, the row. CSS reads it as var(--r), JS as A.ROW.

        
Type
Geist Mono, 14px on 21px, at every width. Charts are 12px on 14px.

        
Weights
300 body text. 400 gray text, the bar, the sidebar. 700 frames, slabs, titles.

        
Targets
44px to tap: one row plus 12px above and below.

      


      
Ramp

      
Weight is density. The ramp is nine steps, space to @, and the index is how loud a character is. The ramp editor in Themes swaps the characters, not the order.

      
The ramp, space to at sign, index 0 to 8, with what each step is for.

.1 dotThe quietest mark. Tracks, dots, empty cells.

#6 hashWalls. Cards.
